# 三视角融合与连通分区对照

使用 [新输入流程](DATASET_SPEC.md)生成的 101 个街区（SoHo 67、Hudson Yards 34）。Overture POI 置信度只作为来源字段保存，实验不读取分数，不按它过滤或加权；营业状态也没有在本轮改变。步行邻接来自已绘制路网，不做门点吸附，不按共享边界长度删边。

两区互相整区留出，随机种子为 13、29、53。每个种子只训练一套视角编码器：POI、建筑、步行各自训练，用同一街区的两种编码作对比，分别得到 64 维向量。比较融合时冻结编码器。等权融合归一化并拼接三路向量；注意力融合沿用同样的拼接结构，只在训练区学习每个街区的视角权重。没有观测的视角不给权重；三个视角都缺失的街区保留为孤立块。

对每套融合向量固定同一组相似度和邻接，比较两种分区方法：

- **树上选层**：只从相邻街区的完全链接合并树选标准加权模块度最高的一层。
- **逐块重分组**：分别从树上选层结果、每个街区单独成组出发。允许街区移到邻组或独立成组，要求拆分后的组和新组都步行连通。只接受能提高同一目标的移动，最终取两个起点中模块度更高的结果。没有设定相似度截止值、目标片区数、面积门槛或停止容差。

两种方法都只在步行邻接边使用 `(1 + cosine) / 2` 权重。完成两个测试区的预测并保存后才读取 BID。下表为三个种子均值；BID 只衡量与官方管理边界的重叠。参考面限制在本轮可用街区内，因此不把这些 IoU 与旧街区口径直接比较。

| 融合 | 分区 | SoHo IoU | SoHo 多圈 / 漏圈（公顷） | Hudson Yards IoU | Hudson Yards 多圈 / 漏圈（公顷） |
| --- | --- | ---: | ---: | ---: | ---: |
| 等权拼接 | 树上选层 | 0.403 | 5.65 / 1.99 | 0.275 | 19.39 / 5.70 |
| 等权拼接 | 逐块重分组 | 0.482 | 6.41 / 0.71 | 0.328 | 9.72 / 7.08 |
| 注意力拼接 | 树上选层 | 0.371 | 5.43 / 2.40 | 0.240 | 5.50 / 9.76 |
| 注意力拼接 | 逐块重分组 | 0.400 | 6.00 / 1.85 | 0.380 | 6.16 / 6.97 |

逐块重分组在两区、两种融合下均提高平均 IoU，但在 SoHo 两种融合都多圈了更多面积，IoU 提升来自漏圈减少。融合的胜负依地区变化。下一轮保留等权拼接和逐块重分组作为简单对照，优先检验改变分区目标能否减少多圈，同时监测漏圈。BID 不用于选择目标的参数。

```sh
.venv/bin/python experiments/fusion_partition_benchmark.py prepare --output outputs/fusion_partition_repeat
.venv/bin/python experiments/fusion_partition_benchmark.py score --output outputs/fusion_partition_repeat
```

本轮冻结输出在 `outputs/fusion_partition_topology_v2/`。另存输入文件哈希、逐种子的视角向量、融合权重和分区，方便复核。
