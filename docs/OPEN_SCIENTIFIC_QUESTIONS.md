# 开放科学问题清单（漏洞账本）

日期：2026-11-15。来源：Flushing 留出区判决后的复盘讨论。每个问题标注它动摇的既有结论与关闭路径；关闭前，相关结论按本清单限定适用范围。配套证据：[Flushing 判决](FLUSHING_HELDOUT_VERDICT.md)、[E4 文档](E4_CONNECTED_CANDIDATES.md)、[标注协议](STREETVIEW_ANNOTATION_PROTOCOL.md)。

## 现状交代（问题的共同根源）

- **研究窗口**：研究者手画矩形，无协议、无敏感性分析。SoHo/HY 沿用早期画框；Flushing 冻结窗口中心比 Main St 站实际坐标偏北约 2-3 个街区，把大片居住腹地圈进样本（共识 D 类块 14/22 在核心以北）。窗口是**未声明的先验**。
- **机位采样**：沿块内步行路段每 35 m 均匀采样（非"四边界各一张"）。在块内同质的 SoHo 无偏；在"一面商业三面背街"的 Flushing 构成对商业立面的系统性欠采样。
- **标签规模**：每个新区需要街景抓取 + 两名标注者；GSV 不覆盖中国——数据源可移植性是硬约束。

## G5 循环性总账：独立性矩阵不存在

| 项 | 内容 |
| --- | --- |
| 提问 | 若让模型候选定义标注范围（G1 的选项之一），评价被候选生成污染；继续手画框，框的任意性污染标注分布——两条路都通向循环。项目里"输入与裁判同源"共几处，谁盘点过？ |
| 已知三处 | ①用审计结果改方法（2026-11-15 犯过一次，已撤销并记录于 [E4 文档](E4_CONNECTED_CANDIDATES.md)）；②两个开发区反复用于开发与评价；③v1 三元组采样依赖模型相似度做分层 |
| 关闭 | 写出决策×评价的独立性矩阵，结论按矩阵分级；新区协议显式声明每项输入的来源禁区 |

## G6 "迁移"是多轴词，单轴使用即混淆

| 项 | 内容 |
| --- | --- |
| 提问 | Flushing 一趟换了地理、布料类型（浏览→串联）、标注难度、POI 分布（购物占比 64%→31%）四样东西，衰减却记在"迁移"一个词头上。哪根轴贡献多少？ |
| 动摇 | "部分迁移"结论的精度；论文中任何不带轴名的泛化表述 |
| 关闭 | 分解实验：同城市换布料 / 同布料换城市 / 同区换标注者，一次一根轴；用 POI 构成比做分层回归量化分布偏移的贡献 |

## G7 标签的认证经济学：裁判不规模化

| 项 | 内容 |
| --- | --- |
| 提问 | 正确问题不是"全球是否都要标注"，而是：**多少个区型的标签能认证多大范围的免标签部署？**外推法则不存在；现有 2.5 个区型（浏览密集/天花板/串联型）远不够。校准成本（判据卡+例题）随标注者线性增长，成本模型没人算过 |
| 动摇 | 数据集发布的适用范围声明；"迁移到中国城市"的可行性表述（GSV 缺位） |
| 关闭 | 先定义城市布料的区型分类学；每型一区的认证计划；中国街景替代源（Mapillary 稀疏、百度无开放 API）给出明确答案或明确放弃 |

## G8 任务定义缺口：评价是分析型的，任务是推荐型的

| 项 | 内容 |
| --- | --- |
| 提问 | "在官方围栏上叠加可逛范围"的退化方案诱人，因为围栏白送了任务定义。原始主张（发现边界）至今没有任务级成功标准——用户拿到的候选片区，怎样算推荐对了？ |
| 动摇 | E5 的存在性（没有指标就没有实验） |
| 关闭 | 在 E5 之前定义任务指标（预算内模式匹配度、覆盖率、独立满意度），写入 SOP 作为新条目 |

## 优先级建议（当前判断，可被推翻）

1. **G4 + G2**（stroll 字段 + 街道走廊试点）：成本低、直接回应"法拉盛不好逛"的构念错位，且给无围栏区一个落子点
2. **G1 敏感性实验**：重画紧凑 Flushing 窗口新冻结重标，拆"窗口账"与"模型账"——是修正迁移判决的必要条件
3. **G5 独立性矩阵**：写文档级别，半天
4. G3（单位下移）与 G6（分解实验）随 G1/G4 结果自然启动
