# PACE 任务边界审计与分阶段实验建议

审计日期：2026-11-11。责任：任务定义、科学结论边界、六个 RGSCL 参考辅助脚本。只读审查历史实验和参考代码，未修改历史数据或历史分数。文中的路径相对项目根目录。

## 1. 决策

不把下一步定义为“再换一个模型赢过同楼比例”。当前需要先证明标签、缺失机制和表征目标符合问题，再比较编码器。现有两区适合诊断和验证代码；它们不能继续充当未观察过的最终测试区。

**交叉审计发现阻断性错误：旧 RGSCL 以区内局部 `block.key` 缓存建筑图，跨区同名ID发生冲突。参数代理实测，SoHo 49个可评分街区中12个、Hudson Yards 11个中5个读取了错误建筑图。旧 RGSCL 外区指标和胜负解释必须撤回；不能先归因为参数未调好、模型不适合或数据规模。修复需以 `(area, block.key)` 标识实体并验证缓存与直接构图一致，然后重新评估。旧数值只能作为受缺陷影响的历史产物。**

建议最终问题明确为：**在给定出发位置、可用时间和探索偏好的条件下，从步行可连通的多尺度候选片区中，推荐更符合用户探索方式的区域。研究商业探索，但允许文化、休闲和混合片区成为候选，不能把非商业区先验标为不适合 Citywalk。**

第一阶段只研究“微单元表征能否识别可独立验证的商业探索组织方式”；第二阶段才研究合并；第三阶段才研究推荐。不同阶段需要不同真值和评价。

更精确的代理目标：若隐藏且唯一建筑匹配记录数为 N，各建筑中记录数为 n_b，则 y=Σ_b n_b(n_b−1)/[N(N−1)]，N<2 时不可评分。这里的“建筑”是来源中的 footprint，不自动等于商业综合体或公共室内空间。

可见同楼比例是必须保留的强基线。随机遮盖使可见和隐藏两半来自同一街区的同一总体，直接估计与目标天然一致。它获胜说明该任务可能不需要复杂表征；不能据此认定建筑数据无用，也不能用复杂模型输赢推断 Citywalk 表征是否成功。有限记录产生的目标波动应单独报告。

## 3. 需要纠正的结论与边界

1. **构念混淆。** 同楼高集中可以是商场，也可以是同一建筑的互不连通临街门店；同一个室内综合体可以跨多个 footprint。应区分 footprint、商业综合体、入口和公共可通行室内区域四种实体。仅凭点落面不能产生独立探索风格标签。
2. **访问流不等于入口。** 街区或区域之间的 OD 访问量最多提供区域联系证据，无法分辨一栋楼的多个入口。只有入口级观测或带可验证路径/门点的轨迹才能支持“哪个入口使用更多”。当前快照没有此类入口流量标签；两个人工核验门点也不能外推为所有入口。结构代理确认 `walking_lines` 只读取 NYCWalks geometry；门点来自 `areas.json` 人工指定及 OSM `entrance=main` 核验，当前代码并未通过访问流识别主入口。
3. **样本总体受筛选。** 置信度、类别筛选、内区街区、步行主分量、唯一建筑匹配及隐藏 N≥2 都改变评价总体，缺失不是零。结构审计量化：Hudson Yards 合格商业 POI 444→入选街区260→唯一建筑匹配191；SoHo 2057→1547→1161。所有指标应带各层覆盖率；不要把匹配子集误称全体商业店铺。
4. **测试身份不能重置。** `step3/README.md:61,111,128` 已承认两个外层区域反复被观察。以后即使代码严格先 select 后 test，仍只能作为诊断；新标签如果来自同两区，也不是空间独立新测试。当前不加数据时先做诊断，将最终确认留给未查看过的区域。
5. **有效样本数。** 同一街区的多次遮盖不是多个独立街区；不同初始化也不是多个独立地理样本。结果可在街区内先平均并配对报告；同一区相邻街区也有关联，两个区不足以支撑城市级显著性结论。
6. **RGSCL 性能口径。** 作者下游是城市功能分类、房价和 check-in 映射（`references/RGSCL/code/README.md:80–82`），当前是[0,1]同楼比例回归。指标量纲、任务、标签、规模不同，不能以绝对误差直接比较数量级。公开数据说明包含 mocked 数据（同文件:13–20），本地也未执行其原始真实数据 benchmark。
7. **RGSCL 是适配方案而非精确原版复现。** PACE 自行实现跨视角/区间 balanced softplus 损失（`step3/rgscl.py:118–148`），对退化几何和稀疏区也有适配。GATv2 对照还用归属与步行图；差值不能只归因于 GAT/GATv2。
8. **旧设想的先后顺序需要重写。** 原 proposal:29 先按道路统计划候选、30 再编码；用户目前要微单元 embedding 决定连接。新流程应是输入→微单元表征→受步行邻接约束的候选层级→偏好排序。

## 4. “不要自定义阈值”的可执行解释

最终分区不能继续用余弦0.55/0.65/0.80、固定 K 或“最多几个街区”决定输出。旧 step2 的这些规则只保留为历史探索。

近期最稳妥做法是先输出**完整的、只允许步行邻接合并的层级树**，不宣称存在唯一正确切口。每次选择相似度最高的合法相邻合并，固定 tie-break 与不相连分量规则；保留全部层级作为候选，再由用户给定预算和偏好排序。这满足“不手设相似度截止值”，但平均/完全链接选择仍是模型假设，需要对照验证。

如果论文必须输出唯一分区，另立实验比较明确概率模型下的最短描述长度（MDL）选切口。必须写清数据编码项、分区复杂度项、嵌入归一化、连通性约束和优化算法，不能将“MDL”三个字当作自动合理的保证，也不能暗中增加调到好看的分辨率系数。展示全单点/单大区极端解和规模敏感性。

几何坐标误差容差、来源 POI 质量筛选与分区语义阈值不是同一种参数。用户要求不能被偷换成“换一处设阈值”；所有固定几何处理需登记来源依据及敏感性。若从数据学习参数，只在训练区拟合。用户时间预算是请求条件，不是研究者手调商圈尺度。

## 5. 明确的数据、标签与模型合同

| 层级 | 输入 | 训练目标/标注 | 预测与评估 |
| --- | --- | --- | --- |
| 数据关联诊断 | 原始 POI、footprint、道路和门点；保留来源及时间 | 唯一/多重/未匹配；人工证据记录，不把最近建筑当真值 | 匹配覆盖、人工错误类型、入口可达证据完整性 |
| 代理补全 | 仅可见 POI，公开底图；严格隐藏 POI 类别/位置/关系 | 现有隐藏记录同楼比例，仅作合成缺失任务 | 街区等权 MAE、校准、分覆盖率和缺失机制的误差 |
| 探索表征 | 类别、建筑组织、公共步行联系，来源缺失标记 | 独立标注室内公共连通、临街连续探索、混合性；unknown独立；标注者不看预测 | 多标签/连续描述或成对相似度；人工一致性、跨区校准、相似类别难例 |
| 候选区域 | 训练好的微单元 embedding、步行邻接、实际入口 | 不用同一相似度函数当唯一真值；独立边界/连通审阅、候选成对比较 | 连通合法性、扰动稳定性、人工相关性；不只看轮廓美观 |
| 推荐 | 候选区域、出发点、时间预算、用户偏好 | 在相同候选和约束下的成对选择/平局/都不选；后续体验反馈 | 相关性排序、约束满足、用户选择与实际体验；热门度/类别/距离基线 |

标注需保留：实体ID、时间有效性、证据链接/记录、可达的公共入口、公开通行范围、未知原因、独立标注者和裁决记录。不要直接推出没有可观察锚点的“0–3逛街感”。先试标形成可重复判断准则，再锁定标注规约。商业是主要研究域；少量文化/公园/混合片区用于检验“商业才算 Citywalk”的错误假设，不能一律作为负例。

如果之后引入街景或文本模型，冻结生成流程并核验标注，避免将同一生成模型同时作为特征、标签和裁判；本轮不依赖新增外部数据或模型。

## 6. 下一步实验方向及推进条件

| 次序 | 要回答的问题 | 最小对照与限制 | 推进条件 |
| --- | --- | --- | --- |
| E0 合同与实现核验（现在） | 每个字段和标签是否符合定义、隐藏是否真正隔离？ | 微型人工构造图：同 footprint 不同入口、跨 footprint 同综合体、未匹配POI、共享源道路、完全相同两视角；校验污染路径与无目标张量 | 已知答案全部符合合同；输出覆盖/未知/剔除清单；历史结果可追溯。只编译通过不够 |
| E1 缺失机制诊断（现有数据） | 直接统计为何胜出、模型是否只是跟随训练区均值？ | 保留原随机一半遮盖；另做整建筑/类别成组缺失压力测试。直接统计、训练区均值、训练内收缩估计、正则回归；报告隐藏可匹配数和目标方差。压力测试不冒充真实缺失 | 能区分抽样噪声、样本筛选、分布偏移和模型误差；若简单方法足够，停止为该代理堆GNN |
| E2 同信息模型/目标消融（现有数据，诊断） | 增益来自图、双视角还是目标函数？ | 固定数据、词表、归一化、遮盖、统计输入、读出头、预算；统计/DeepSets无图、GAT、GATv2；再做双视角有/无区间负对比。建筑辅助暂不默认加入；正则与停止轮次在训练内选择 | 代码层面受控，改善能跨两个方向及初始化解释；不因单方向细小改善宣布胜出，不重复用旧外层成绩选模型 |
| E3 标签有效性与新区域确认（后续数据阶段） | embedding真的区分探索方式，而非POI数量/类别？ | 先独立双人试标，加入类别与密度相似而公共通行组织不同的难例；标签规约锁定后，在从未用于设计的新区域盲评。共享建筑/源道路/重叠候选隔离 | 独立标注可复现，模型较简单统计提供稳定增量，结论附适用总体和不确定性；无此证据不进入推荐效果宣称 |
| E4 无手设截止值的连通候选（后续） | 相似embedding能否组成有用的可走片区？ | 固定embedding先比较完整连接层级、仅步行/几何基线；如需唯一分区再比较显式MDL。独立评估，不以用于合并的余弦相似度自证 | 真实步行连通成立、候选在输入扰动下稳定、有独立用户或专家证据支持语义；同时排除全单点/单大区退化 |
| E5 推荐价值（最后） | 表征和分区是否改善用户选择？ | 先固定候选测试排序：距离/类别/热门度 vs 加探索表征；再固定排序测试候选生成。记录平局/都不选，拆分用户与区域 | 相同候选/预算下用户效用有可解释改进；候选变化与排序变化不能混算为同一模块增益 |

不规定任意“提高X%就通过”。预先锁定主比较与指标，报告效应和置信区间/不确定性；地理确认需足够独立区域，不能把本轮重复遮盖或种子当作扩大地理样本。当前优先执行 E0→E1，再决定 E2；E3–E5 是明确研究路线，不在一次运行中承诺全部解决。本轮不扩充数据；独立人工标注、未观察新区域和用户反馈均属于未来阶段。

对外可以凝练为五步：①修复缓存与任务合同，已有答案验证通过后重评；②现有数据缺失诊断与同信息模型消融，解释不了简单基线之前停止堆模型；③未来独立标签与新区域确认，不能区分探索方式就不进入分区效果宣称；④无手设截止值的连通候选，连接和语义验证均通过再进入推荐；⑤固定候选/固定排序分别评估推荐增量。每一步都允许以负结果停止复杂路线。
