# E4：连通多尺度候选（可靠性加权融合 + 画像选层 + 预算变焦）

常设约束（本文件及后续所有实验适用）：**不添加任何手设阈值**——无相似度截断、无目标片区数、无停止容差、无"低于 X 不切"之类的规则。方法里的每个常数都要写明出处；看到审计数字不好看之后回头加规则，属于用裁判改方法，一律不允许（本轮曾犯一次并已撤销，见文末）。

## 管线

```
冻结逐视角向量 ─→ 可靠性 r_v(块) = 观测 × 三种子近邻集 Jaccard（k∈{3,5,7} 网格平均）
              ─→ 融合 = concat( sqrt(r_v/Σr)·z_v )，POI+步行
              ─→ 完整链接合并树（步行邻接约束）
              ─→ 画像选层（001 选，平滑 Welch t）
              ─→ 预算变焦：游时 = 片区内部步行长 ÷ 4.5 km/h（文献步行速度，唯一物理常数）
                 预算内能装下的最细连通候选，逐枝下钻；预算是用户输入
```

可靠性加权统一处理缺失型与弱视角型（缺失= r 0 的特例），[消融](VIEW_ABLATION.md)后建筑视角不参与。

## 结果（001/002 双标口径；003 归档于 responses_uncalibrated/）

**融合变体（002 审计的组内-跨组边分离，三种子均值）**

| 区 | 等权 | 可靠性加权 |
| --- | --- | --- |
| SoHo | +0.160 | **+0.182** |
| Hudson Yards | −0.042 | −0.050（标签天花板区，两者皆零信号） |

**预测侧（共识标签 LOO-1NN）**：等权 密度 81%/连续性 76%；可靠性 76%/73%。等权略利于预测、可靠性利于分区对齐——两者用途不同，同时保留。

**预算变焦（SoHo，可靠性树）**：15→30 分钟预算约 44→33 个候选；**b014（大入口块）在 ≤30 分钟独立、45 分钟挂靠 6 块组、≥90 分钟进 13 块组**——"细尺度独立、粗尺度挂靠"由可靠性加权自动涌现，无任何规则干预。

**诚实记录的张力**：SoHo 的纯步行时预算切分在各预算档审计对比均为负（−0.09~+0.01）——步行时间尺度与画像纹理尺度在 SoHo 不重合（树细端的合并是步行微结构，不是纹理单元）。HY 相反（小预算 +0.14，大预算转负）。这不是缺陷被掩盖的理由：预算候选的纹理对齐需要在更多区验证，或由用户偏好层（模式字段）补足。

## 常数出处清单

| 常数 | 值 | 出处 |

| 步行速度 | 4.5 km/h | 文献常用值，唯一物理常数；无每店停留时间（已删） |
